# Rock Paper Scissors Game

A classic **Rock Paper Scissors** game made using **HTML**, **CSS**, and **JavaScript**.  
Play against the computer, keep track of your scores, and enjoy the responsive UI.

---

## Features

- Simple UI with hand icons for Rock, Paper, and Scissors
- Player vs Computer interaction
- Real-time score tracking
- Game result display (Win/Loss/Tie)
- Reset button to start fresh anytime

---

## How to Play

1. Click on **Rock**, **Paper**, or **Scissors** to make your move.
2. The computer randomly selects its move.
3. Results are shown instantly along with score updates.
4. Click **Reset** to restart the game.

---

## Tech Stack

- **HTML** – Structure of the game
- **CSS** – Basic styling
- **JavaScript** – Game logic and interactivity
